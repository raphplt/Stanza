# Décisions d'architecture et d'implémentation

Ce fichier consigne les choix simples retenus lorsque `SPEC.md` laissait une marge d'interprétation.

1. **Identifiants UUID v7 sans dépendance externe** : génération via un helper interne utilisant `crypto.getRandomValues` conforme à la RFC 9562 (horodatage 48 bits + aléatoire).
2. **Développement local avec `@neondatabase/serverless`** : en développement local (`db.localtest.me` ou `localhost`), `neonConfig.fetchEndpoint` cible le proxy HTTP Neon local (`http://localhost:4444/sql`) tandis que `drizzle-kit` utilise `DATABASE_DIRECT_URL` (ou `DATABASE_URL` en production).
3. **Stockage local de repli pour Vercel Blob** : si `BLOB_READ_WRITE_TOKEN` est vide en développement local, les uploads d'images et les sauvegardes écrivent dans `.local-blobs/` et les images sont servies via `/api/upload/local/[...path]`, afin que tous les flux (éditeur, avatar, sauvegarde/restauration) fonctionnent hors-ligne et en test sans compte Vercel. En production avec `BLOB_READ_WRITE_TOKEN`, `@vercel/blob` est utilisé directement.
4. **Compression ZIP sans dépendance lourde** : utilisation de `fflate` (`zipSync` / `gzipSync` / `gunzipSync`) pour l'export ZIP des textes d'un auteur et des sauvegardes.
5. **Liens d'invitation recopiables** : le token d'une invitation est un HMAC-SHA256 de son identifiant avec `BETTER_AUTH_SECRET`. Seul son SHA-256 est stocké en base, comme pour les autres tokens, mais l'admin peut régénérer le lien d'une invitation en attente pour le recopier. Changer le secret invalide les invitations en cours. Les liens de réinitialisation restent aléatoires et ne sont affichés qu'une fois.
6. **« Masquer » dans la modération** : passe un texte publié en non listé (retiré du profil, du sitemap et des flux, lien privé conservé). « Dépublier » le renvoie dans les brouillons de l'auteur.
7. **Réactions sur les textes non listés** : la barre de réactions apparaît aussi sur `/s/[shareId]`, avec les mêmes règles.
8. **CSP sans nonce** : un nonce imposerait un rendu dynamique de chaque page et casserait le prérendu partiel. La CSP autorise donc `'unsafe-inline'` pour les scripts et styles, mais bloque objets, frames, `base-uri` et origines de formulaire tierces. `img-src` accepte `https:` car un texte peut contenir une image collée depuis le web.
9. **Images Open Graph** : générées avec `next/og` et la police Newsreader (fichiers `.woff` sous licence OFL dans `src/assets/fonts`, Satori ne lisant pas le woff2). L'image choisie pour un texte remplace la carte typographique si elle est en PNG, JPEG ou GIF.
10. **Purge à 30 jours** : faite par le cron de sauvegarde, après l'export, pour les comptes supprimés, les textes en corbeille et les sessions expirées.
11. **Export auteur** : servi par `/studio/export` (route protégée par la session) plutôt qu'une Server Action, pour un téléchargement direct du ZIP.
12. **Next.js 16 Streaming 404 et Prerendering** : pour garantir de vrais en-têtes HTTP 404 avant le démarrage du streaming sur les routes publiques (`/[pseudo]`, `/[pseudo]/[slug]`, `/s/[shareId]`), les données publiques sont résolues avant le rendu JSX. Les routes privées ou avec `searchParams` direct (`/studio`, `/[pseudo]`) utilisent `export const instant = false;` pour un rendu direct complet sans latence de streaming sur mobile (Lighthouse 100).
13. **Éditeur mobile et interactions** : la barre d'outils tactile mobile utilise `onPointerDown={(e) => e.preventDefault()}` pour préserver le focus de l'éditeur ProseMirror lors des appuis, et les dialogues synchronisent leur valeur immédiatement à l'ouverture. Une règle CSS désactive les pointer-events de `<nextjs-portal>` en développement pour éviter l'interception des taps en bas d'écran.
